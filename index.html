How it works

1

Request your data

In Discord: User Settings → Data & Privacy → Request all of my Data. Discord emails you a download link (can take a few days, up to 30).

2

Drop the zip here

Don't unzip it. Your browser reads the file straight from your disk — streaming even multi-gigabyte telemetry files without uploading a single byte.

3

Explore

Get dashboards for messages, people, servers, telemetry, locations, games and billing. The report is cached in your browser so you can come back later.

🔒

Your package never leaves your computer

  • This is a static website with no backend. There is no server to upload to.
  • The zip is read and processed by JavaScript running in your own browser tab (a Web Worker).
  • A strict Content-Security-Policy blocks the page from sending data anywhere (connect-src 'self').
  • The finished report is stored only in your browser (IndexedDB) and can be deleted with one click.
  • The only outbound requests are images: avatars and custom emoji from Discord's CDN and attachment / GIF previews.
  • Open source — read the code, or download the repo and run it offline.

FAQ

How long does processing take?

Messages, servers and account data take seconds. The telemetry scan reads every tracked event (often several GB) and typically takes 1–5 minutes depending on your device. You can turn it off for a quick look.

Why are only my own messages shown?

Discord's data package only includes messages you sent. Messages from other people aren't part of your package.

Which browsers work?

Any recent Chrome, Edge, Firefox or Safari (2023+). It needs DecompressionStream, which all modern browsers support.

Some names show as "Unknown" or "Server 1234…"

The package only contains IDs for some servers, channels and games. When Discord didn't include a name anywhere, the ID is shown instead.

Is this affiliated with Discord?

No. This is an independent, open-source tool that reads the data package Discord gives you.
